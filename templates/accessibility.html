{% translate "Accessibility" %}

{% translate "HansardLens aims to be usable by everyone, including people who use a keyboard, a screen reader, magnification or a phone. The target is the Web Content Accessibility Guidelines (WCAG) 2.1, level AA, the standard that applies to Government of Canada websites." %}

{% translate "Status" %}

{% blocktranslate with date=reviewed|ldate:"date" %}Reviewed on {{ date }}: the site’s own pages meet WCAG 2.1 AA in the checks described below, with the exceptions listed under “Known limitations”. It has not yet been tested by people who use assistive technology every day.{% endblocktranslate %}

{% translate "What has been done" %}

  • {% translate "The whole interface is available in English and French, and every passage of debate is marked with its language, so screen readers pronounce it correctly." %}
  • {% translate "Every page can be used with a keyboard alone. A “Skip to content” link comes first, and the keyboard focus is always visible." %}
  • {% translate "Text has a contrast of at least 5.7:1 with its background; form fields, chart lines and bars at least 3:1." %}
  • {% translate "Pages reflow to a width of 320 pixels without sideways scrolling, and text can be enlarged to twice its size." %}
  • {% translate "Each chart has a written title, a table with the same figures, and keyboard access: the arrow keys move between months and the values are read out." %}
  • {% translate "Colour never carries meaning on its own: results, votes and parties are written out, and the language actually spoken is marked by a line and a label." %}
  • {% translate "Pages use headings, landmarks and labelled form fields, and every page has its own title." %}

{% translate "Known limitations" %}

  • {% translate "The API documentation page uses a third-party interface (Swagger UI), available in English only, which does not fully meet WCAG 2.1 AA. The same information is in the README on GitHub." %}
  • {% translate "Debate text is reproduced from Hansard as published, including its abbreviations and the House’s own headings." %}
  • {% translate "Party abbreviations (Lib., CPC, BQ, NDP, GP) are not expanded." %}

{% translate "How it was checked" %}

{% translate "Automated testing with axe-core on every type of page in both languages, at desktop and phone widths; keyboard testing of every page; reflow at 320 pixels; contrast computed for every colour pair; and automated tests in the code that check language, headings, landmarks and form labels on each release. The full report is in the project’s documentation (docs/ACCESSIBILITY.md)." %}
